# Como usar este cofre

Use este cofre como mapa operacional do workspace. Ele nao substitui os documentos locais dos projetos; ele aponta o que deve ser lido, quais limites existem e qual caminho seguir para investigar com seguranca.

## Fluxo recomendado

1. Comece por [[Leitura obrigatoria]].
2. Confirme as regras em [[Preflight obrigatorio]] e [[Regras operacionais]].
3. Se envolver Git ou GitHub, abra [[Git e GitHub]].
4. Se envolver biblioteca ou JAR, abra [[Libs complementares]].
5. Escolha a nota do projeto em [[Workspace VsCodeProject]].
6. Para entender o servidor local, use [[MCP vscodeproject-context]] e [[Resources e Tools]].
7. Em tarefas do `webtrans`, complemente a leitura com os resources
   `context://webtrans/obsidian-vault`,
   `context://webtrans/obsidian-routine-routing` e
   `context://webtrans/obsidian-reasoning`.

## Notas principais

- [[Bem-vindo]] e o indice geral.
- [[Mapa mental]] mostra a visao de alto nivel.
- [[Mapa de conexoes]] mostra as dependencias entre arquivos.
- [[Leitura obrigatoria]] resume a ordem que o agente deve seguir antes de agir.

## Convencao do cofre

- Links internos usam o formato de wikilink do Obsidian.
- Cada nota tem `tags` para facilitar busca e grafo.
- As notas sao adaptadas dos `.md` do repositorio `global-mcp-agent`.
- As fontes originais ficam no repositorio raiz; este cofre organiza a leitura para Obsidian.
