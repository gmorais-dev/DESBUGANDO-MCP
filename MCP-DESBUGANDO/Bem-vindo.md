# MCP Desbugando

Este cofre documenta o agente global `global-mcp-agent`, o MCP `vscodeproject-context` e as regras de uso do workspace `/home/dev27/Documentos/VsCodeProject`.

## Entrada rapida

1. Leia [[Como usar este cofre]].
2. Siga [[Leitura obrigatoria]] antes de atuar no workspace.
3. Consulte [[Mapa mental]] para enxergar as conexoes principais.
4. Use [[Mapa de conexoes]] quando precisar navegar por relacoes entre notas.

- [[Preflight obrigatorio]]: checklist antes de qualquer acao.

- [[Git e GitHub]]: limites de consulta e mudanca de estado.
- [[Workspace VsCodeProject]]: projetos e relacoes entre repos.
- [[MCP vscodeproject-context]]: escopo, instalacao e validacao do MCP local.
- [[Libs complementares]]: JARs internos e cuidados de runtime.

O MCP e o cofre existem para orientar consultas seguras. Mudancas de codigo, Git, GitHub, banco ou runtime seguem as permissoes descritas em [[Preflight obrigatorio]], [[Regras operacionais]] e [[Git e GitHub]].
